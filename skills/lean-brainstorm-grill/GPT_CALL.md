# GPT Call

在 ChatGPT 中使用时，粘贴下面这段即可：

```text
请读取并遵循这个 Skill：
https://github.com/fyjk999-cyber/ponytail/blob/main/skills/lean-brainstorm-grill/SKILL.md

使用 lean-brainstorm-grill auto 模式处理接下来的任务：
- 简单任务直接执行，不提无用问题；
- 普通任务最多 2 个关键问题；
- 复杂架构任务最多 3 个关键问题；
- 优先复用已有代码，遵循 Reuse > Modify > Extend > Create；
- 只做 Minimum Effective Diff；
- 禁止无关重构、过度抽象和不必要代码；
- 完成后做最小必要验证。
```
